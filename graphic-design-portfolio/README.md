## File structure

- `editable/` — vector source files that can be edited in Figma, Inkscape, Illustrator, or a text editor.
- `previews/` — ready-to-share PNG exports at 1080 × 1080 pixels.
- `contact-sheet.png` — a single gallery view of all projects.

All artwork and layouts in this collection are original portfolio concepts.
