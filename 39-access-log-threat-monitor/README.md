# Access Log Threat Monitor

A defensive, offline web-log analyzer that highlights repeated errors and sensitive-path requests for human review.

## Why this belongs in my portfolio

This project connects directly to the skills and practical experience listed in my CV.

## Features

- Parses standard combined access-log lines
- Flags repeated 401, 403, and 404 responses
- Highlights requests to commonly protected paths
- Produces source-IP and alert summaries

## Skills demonstrated

Python, cyber security, log analysis, incident monitoring

## Run

    python app.py sample_access.log
    python test.py

- app.py
- sample_access.log
- test.py
