# 01 — Retail Sales Dashboard

**Question:** Which product categories and months generate the most revenue?

The script cleans transaction data, calculates revenue and order KPIs, ranks categories, and creates a two-panel sales dashboard.

```bash
python analysis.py
```

**Output:** `outputs/retail_sales_dashboard.png`

**Skills:** pandas aggregation, KPI design, time-series analysis, Matplotlib dashboards.
