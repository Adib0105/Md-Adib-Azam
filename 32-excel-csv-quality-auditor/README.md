# Excel CSV Data Quality Auditor

A zero-dependency data-cleaning tool for CSV files exported from Excel, with missing-value, duplicate, email, and numeric-field checks.

## Why this belongs in my portfolio

This project connects directly to the skills and practical experience listed in my CV.

## Features

- Column-level completeness profile
- Duplicate row and duplicate email detection
- Email and numeric-value validation
- Machine-readable JSON audit report

## Skills demonstrated

Python, MS Excel workflows, data cleaning, CSV automation

## Run

    python app.py sample_customers.csv --numeric age
    python test.py

## Project structure

- app.py
- sample_customers.csv
- test.py

All included sample data is synthetic and safe to publish.
