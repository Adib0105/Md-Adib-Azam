# Java Customer Feedback Analyzer

A Java command-line application that summarizes customer ratings and uses transparent keywords to classify feedback tone.

## Why this belongs in my portfolio

This project connects directly to the skills and practical experience listed in my CV.

## Features

- CSV input using Java standard libraries
- Rating summary and sentiment counts
- Reusable feedback record class
- Graceful handling of malformed rows

## Skills demonstrated

Java, file handling, customer experience, text analysis

## Run

    java FeedbackAnalyzer.java sample_feedback.csv
    python test.py

## Project structure

- FeedbackAnalyzer.java
- sample_feedback.csv
- test.py

All included sample data is synthetic and safe to publish.
