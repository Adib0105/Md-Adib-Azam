# SEO Page Auditor

An offline HTML auditor that scores essential on-page SEO elements without crawling or sending data to external services.

## Why this belongs in my portfolio

This project connects directly to the skills and practical experience listed in my CV.

## Features

- Title and meta-description checks
- Heading, image alt text, link, and canonical analysis
- Actionable issue list and 100-point score
- JSON output suitable for reports

## Skills demonstrated

Python, HTML, SEO, automation

## Run

    python app.py sample_page.html
    python test.py

## Project structure

- app.py
- sample_page.html
- test.py

All included sample data is synthetic and safe to publish.
