# C Employee Records Analyzer

A C language command-line program that loads employee records from CSV and reports team headcount, average performance, and top performer.

## Why this belongs in my portfolio

This project connects directly to the skills and practical experience listed in my CV.

## Features

- CSV file input with validation
- Structures and fixed-size arrays
- Department filtering
- Summary calculations in portable C

## Skills demonstrated

C language, structs, file handling, business reporting

## Run

    gcc -std=c11 -Wall -Wextra employee_records.c -o employee_records
    ./employee_records sample_employees.csv Support
    python test.py

## Project structure

- employee_records.c
- sample_employees.csv
- test.py

All included sample data is synthetic and safe to publish.
