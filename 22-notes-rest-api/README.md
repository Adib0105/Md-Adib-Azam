# 22 — Notes REST API

A dependency-free HTTP API with create, list, read, update, and delete endpoints, JSON validation, and real endpoint tests.

```bash
python main.py --port 8000
python test_main.py
```

Endpoints: `GET/POST /notes`, `GET/PUT/DELETE /notes/<id>`.

**Skills:** REST APIs, HTTP status codes, JSON validation, API testing, Python standard library.
