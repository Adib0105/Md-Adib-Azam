# 49. Tableau Campaign Performance

**Tool:** Tableau  
**Dataset:** [`../../datasets/marketing_campaigns.csv`](../../datasets/marketing_campaigns.csv)

## Business question

Which channels win on reach and return?

## KPIs

- ROAS
- CTR
- CVR
- Spend

## Workflow

1. Import the linked CSV and confirm data types.
2. Check missing values, duplicate keys and invalid ranges.
3. Create the calculations in `calculated_fields.txt`.
4. Validate totals against a simple grouped summary.
5. Present one decision, supported by the KPI output.

## Deliverable

Open [`calculated_fields.txt`](calculated_fields.txt) for the reproducible analysis. The source data is intentionally small so every result can be checked manually before scaling to a larger dataset.

## Portfolio talking point

This project demonstrates how I translate a business question into clean metrics, a repeatable analysis and a decision-ready output using Tableau.
