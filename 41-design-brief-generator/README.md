# Graphic Design Brief Generator

A structured creative-brief generator that turns a client request into objectives, audience, deliverables, style direction, and review questions.

## Why this belongs in my portfolio

This project connects directly to the skills and practical experience listed in my CV.

## Features

- Validates incomplete client requests
- Creates channel-specific deliverables
- Suggests an editable visual direction and palette
- Exports a Markdown brief for client approval

## Skills demonstrated

Python, graphic design workflow, automation, JSON

## Run

    python app.py sample_request.json --output creative_brief.md
    python test.py

## Project structure

- app.py
- sample_request.json
- test.py

All included sample data is synthetic and safe to publish.
