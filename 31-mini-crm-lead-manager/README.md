# Mini CRM and Lead Manager

A lightweight SQLite CRM that imports leads, calculates an explainable opportunity score, and shows follow-up priorities.

## Why this belongs in my portfolio

This project connects directly to the skills and practical experience listed in my CV.

## Features

- Lead import from CSV
- Opportunity scoring by value, stage, and follow-up status
- Pipeline summary by stage
- Parameterized queries and repeatable demo data

## Skills demonstrated

Python, SQLite, CRM operations, sales analytics

## Run

    python app.py --database crm.db --import-csv sample_leads.csv --dashboard
    python test.py

## Project structure

- app.py
- sample_leads.csv
- test.py

All included sample data is synthetic and safe to publish.
