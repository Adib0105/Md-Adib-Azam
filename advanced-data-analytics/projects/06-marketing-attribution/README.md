# 06. Multi-Touch Marketing Attribution

## Business problem

Measures the incremental contribution of channels across customer journeys.

## Analytics approach

Path analytics, removal effects, assisted conversions, budget guidance. The pipeline generates a deterministic, realistic dataset, trains or calculates the analytical model, evaluates decision-focused KPIs, and writes a machine-readable metrics file plus a management brief.

## Run

```bash
python advanced-data-analytics/projects/06-marketing-attribution/app.py
```

## Deliverables

- Reproducible data simulation and analytical pipeline
- Model or decision metrics in `metrics.json`
- Actionable recommendations in `decision_brief.md`
- Smoke-tested execution through the collection CI
