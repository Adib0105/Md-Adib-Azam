# 15. Social Network Influence Analytics

## Business problem

Ranks influential accounts and measures concentration and community structure.

## Analytics approach

PageRank from scratch, graph components, influence concentration. The pipeline generates a deterministic, realistic dataset, trains or calculates the analytical model, evaluates decision-focused KPIs, and writes a machine-readable metrics file plus a management brief.

## Run

```bash
python advanced-data-analytics/projects/15-social-network-influence/app.py
```

## Deliverables

- Reproducible data simulation and analytical pipeline
- Model or decision metrics in `metrics.json`
- Actionable recommendations in `decision_brief.md`
- Smoke-tested execution through the collection CI
