# Retargeting / Remarketing Campaign

## Objective
Create a segmented remarketing system for users who showed intent but did not complete the desired action.

## Audience Segments
Website visitors, product/service page visitors, cart/lead-form abandoners, video engagers and previous customers.

## Message Sequencing
Reminder → objection handling → proof → incentive/urgency → final CTA.

## Exclusions
Exclude recent converters from acquisition ads and control frequency to reduce waste and fatigue.

## Target KPIs
Return visits, conversion rate, CPA, frequency, assisted revenue/leads and incremental conversions.

## Deliverables
Audience map, message sequence, exclusion plan, creative matrix and optimization rules.
