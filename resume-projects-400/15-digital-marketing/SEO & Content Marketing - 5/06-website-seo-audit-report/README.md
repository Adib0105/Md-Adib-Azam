# Website SEO Audit Report

## Objective
Create a structured SEO audit framework for a small-business website covering technical, on-page and content issues.

## Audit Areas
- Title tags and meta descriptions
- H1/H2 structure
- URL cleanliness
- Internal linking
- Image alt text
- Indexability and sitemap checks
- Mobile usability and page-speed observations
- Content gaps and search intent

## Priority Model
Issues are classified as Critical, High, Medium or Low based on likely search impact and implementation effort.

## Deliverables
Audit checklist, issue-priority matrix, recommended fixes and 30-day action plan.

## KPIs to Track
Organic clicks, impressions, CTR, average position, indexed pages and conversions from organic traffic.
