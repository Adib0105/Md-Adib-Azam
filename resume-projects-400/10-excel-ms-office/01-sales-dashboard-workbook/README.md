# Excel Sales Dashboard Workbook

A formula-driven workbook for editable sales data, KPI reporting and category comparison.

## Workbook structure

- **Dashboard sheet:** calculated KPI summary and native comparison chart
- **Data sheet:** structured editable source table
- **Formula coverage:** 45 formulas in the current workbook
- **Visual evidence:** rendered `preview.png` for quick review without Excel

## Files

- [`sales-dashboard-workbook.xlsx`](sales-dashboard-workbook.xlsx) — editable Excel workbook
- [`preview.png`](preview.png) — rendered dashboard preview

## Use

Open the workbook in Excel or a compatible spreadsheet application. Replace source inputs on the Data sheet; calculated fields and dashboard formulas are already connected.

This workbook is one of 25 real XLSX projects in the Excel/MS Office track. The collection-wide checker validates workbook structure, formulas and native charts.
