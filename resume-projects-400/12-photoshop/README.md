## ✅ Evidence Standard

A Photoshop project is considered complete only when its folder contains:

- an editable layered **`.psd` source file**
- a final **`.png` or `.jpg` preview**
- the included project **`README.md`** describing the goal and editing approach

Do not treat a project as finished if only the README exists. The README folders below are the production plan for the 25 final Photoshop works.

## Recommended naming

```text
Project-Name.psd
preview.jpg
README.md
```
