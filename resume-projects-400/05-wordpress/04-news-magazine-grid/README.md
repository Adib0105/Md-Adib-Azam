# News Magazine Grid

Creates a responsive news-magazine article grid.

## Install

1. Copy this folder to wp-content/plugins.
2. Activate **News Magazine Grid** in WordPress.
3. Add the shortcode below to a page:

    [adib_04_news-magazine-grid headline="Example" category="Example" summary="Example"]

Security choices: ABSPATH guard, escaped output, sanitized form input and WordPress nonces where forms are used.
