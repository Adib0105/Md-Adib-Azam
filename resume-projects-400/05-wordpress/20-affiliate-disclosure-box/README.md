# Affiliate Disclosure Box

Renders a reusable affiliate disclosure box.

## Install

1. Copy this folder to wp-content/plugins.
2. Activate **Affiliate Disclosure Box** in WordPress.
3. Add the shortcode below to a page:

    [adib_20_affiliate-disclosure-box relationship="Example" merchant="Example" policy_url="Example"]

Security choices: ABSPATH guard, escaped output, sanitized form input and WordPress nonces where forms are used.
