# Local Directory Cards

Renders a local directory card collection.

## Install

1. Copy this folder to wp-content/plugins.
2. Activate **Local Directory Cards** in WordPress.
3. Add the shortcode below to a page:

    [adib_23_local-directory-cards business="Example" category="Example" location="Example"]

Security choices: ABSPATH guard, escaped output, sanitized form input and WordPress nonces where forms are used.
