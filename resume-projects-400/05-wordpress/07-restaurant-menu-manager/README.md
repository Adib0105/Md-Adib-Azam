# Restaurant Menu Manager

Renders structured restaurant menu items.

## Install

1. Copy this folder to wp-content/plugins.
2. Activate **Restaurant Menu Manager** in WordPress.
3. Add the shortcode below to a page:

    [adib_07_restaurant-menu-manager item="Example" category="Example" price="Example"]

Security choices: ABSPATH guard, escaped output, sanitized form input and WordPress nonces where forms are used.
