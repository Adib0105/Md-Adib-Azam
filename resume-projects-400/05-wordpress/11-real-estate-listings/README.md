# Real Estate Listings

Displays responsive real-estate listing cards.

## Install

1. Copy this folder to wp-content/plugins.
2. Activate **Real Estate Listings** in WordPress.
3. Add the shortcode below to a page:

    [adib_11_real-estate-listings property="Example" location="Example" price="Example"]

Security choices: ABSPATH guard, escaped output, sanitized form input and WordPress nonces where forms are used.
