# Podcast Episode List

Creates semantic podcast episode entries.

## Install

1. Copy this folder to wp-content/plugins.
2. Activate **Podcast Episode List** in WordPress.
3. Add the shortcode below to a page:

    [adib_24_podcast-episode-list episode="Example" duration="Example" audio_url="Example"]

Security choices: ABSPATH guard, escaped output, sanitized form input and WordPress nonces where forms are used.
