# Travel Itinerary Cards

Renders a day-by-day travel itinerary.

## Install

1. Copy this folder to wp-content/plugins.
2. Activate **Travel Itinerary Cards** in WordPress.
3. Add the shortcode below to a page:

    [adib_10_travel-itinerary-cards place="Example" day="Example" activity="Example"]

Security choices: ABSPATH guard, escaped output, sanitized form input and WordPress nonces where forms are used.
