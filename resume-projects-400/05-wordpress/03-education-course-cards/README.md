# Education Course Cards

Renders accessible course cards from shortcode attributes.

## Install

1. Copy this folder to wp-content/plugins.
2. Activate **Education Course Cards** in WordPress.
3. Add the shortcode below to a page:

    [adib_03_education-course-cards course="Example" level="Example" duration="Example"]

Security choices: ABSPATH guard, escaped output, sanitized form input and WordPress nonces where forms are used.
