# Membership Content Gate

Shows gated-content guidance based on login status.

## Install

1. Copy this folder to wp-content/plugins.
2. Activate **Membership Content Gate** in WordPress.
3. Add the shortcode below to a page:

    [adib_17_membership-content-gate message="Example" login_url="Example" member_role="Example"]

Security choices: ABSPATH guard, escaped output, sanitized form input and WordPress nonces where forms are used.
