# WooCommerce Offer Banner

Shows a dismissible WooCommerce promotion banner.

## Install

1. Copy this folder to wp-content/plugins.
2. Activate **WooCommerce Offer Banner** in WordPress.
3. Add the shortcode below to a page:

    [adib_09_woocommerce-offer-banner message="Example" coupon="Example" expires="Example"]

Security choices: ABSPATH guard, escaped output, sanitized form input and WordPress nonces where forms are used.
