# Local Business Toolkit

Displays verified business contact details and opening hours.

## Install

1. Copy this folder to wp-content/plugins.
2. Activate **Local Business Toolkit** in WordPress.
3. Add the shortcode below to a page:

    [adib_01_local-business-toolkit business_name="Example" phone="Example" hours="Example"]

Security choices: ABSPATH guard, escaped output, sanitized form input and WordPress nonces where forms are used.
