# Photography Gallery

Renders an accessible photography gallery.

## Install

1. Copy this folder to wp-content/plugins.
2. Activate **Photography Gallery** in WordPress.
3. Add the shortcode below to a page:

    [adib_15_photography-gallery image_url="Example" alt_text="Example" caption="Example"]

Security choices: ABSPATH guard, escaped output, sanitized form input and WordPress nonces where forms are used.
