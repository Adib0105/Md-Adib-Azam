# NGO Donation CTA

Creates an accessible NGO donation call-to-action.

## Install

1. Copy this folder to wp-content/plugins.
2. Activate **NGO Donation CTA** in WordPress.
3. Add the shortcode below to a page:

    [adib_12_ngo-donation-cta campaign="Example" goal="Example" donate_url="Example"]

Security choices: ABSPATH guard, escaped output, sanitized form input and WordPress nonces where forms are used.
