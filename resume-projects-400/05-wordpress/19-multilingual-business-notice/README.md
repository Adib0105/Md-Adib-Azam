# Multilingual Business Notice

Displays a language-labelled business notice.

## Install

1. Copy this folder to wp-content/plugins.
2. Activate **Multilingual Business Notice** in WordPress.
3. Add the shortcode below to a page:

    [adib_19_multilingual-business-notice language="Example" message="Example" contact_url="Example"]

Security choices: ABSPATH guard, escaped output, sanitized form input and WordPress nonces where forms are used.
