# Portfolio Project Grid

Creates a filter-friendly portfolio project grid.

## Install

1. Copy this folder to wp-content/plugins.
2. Activate **Portfolio Project Grid** in WordPress.
3. Add the shortcode below to a page:

    [adib_08_portfolio-project-grid project="Example" technology="Example" url="Example"]

Security choices: ABSPATH guard, escaped output, sanitized form input and WordPress nonces where forms are used.
