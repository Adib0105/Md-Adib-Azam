# Media File Cataloger

A non-destructive media inventory tool that records file type, size, image dimensions, and SHA-256 checksum for design and video project folders.

## Why this belongs in my portfolio

This project connects directly to the skills and practical experience listed in my CV.

## Features

- Recursive file discovery
- PNG, GIF, and JPEG dimension reading without external packages
- CSV catalog export
- Read-only operation with file checksums

## Skills demonstrated

Python, file automation, graphic design operations, data integrity

## Run

    python app.py path/to/media --output media_catalog.csv
    python test.py
