# Student Records and Attendance System

A SQLite-backed student management application for marks, attendance, searchable records, and class performance reports.

## Why this belongs in my portfolio

This project connects directly to the skills and practical experience listed in my CV.

## Features

- Normalized student and result tables
- Parameterized database queries
- Attendance and grade calculations
- Repeatable seed data for demonstration

## Skills demonstrated

Python, SQLite, database CRUD, reporting

## Run

    python app.py --database students.db --seed --report
    python test.py

## Project structure

- app.py
- test.py

All included sample data is synthetic and safe to publish.
