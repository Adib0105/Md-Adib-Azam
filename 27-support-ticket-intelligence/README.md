# Customer Support Ticket Intelligence

A rule-based operations tool that classifies support tickets, estimates priority, detects negative tone, and produces a workload summary.

## Why this belongs in my portfolio

This project connects directly to the skills and practical experience listed in my CV.

## Features

- Ticket category and priority classification
- Negative-tone flag for quick escalation
- CSV enrichment and category summary
- Transparent rules that support human review

## Skills demonstrated

Python, customer support, automation, CSV analytics

## Run

    python app.py sample_tickets.csv --output enriched_tickets.csv
    python test.py

## Project structure

- app.py
- sample_tickets.csv
- test.py

All included sample data is synthetic and safe to publish.
