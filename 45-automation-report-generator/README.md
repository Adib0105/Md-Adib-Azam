# Operations Automation Report Generator

A Python automation tool that converts a task CSV into a polished HTML management report with completion, priority, owner, and overdue insights.

## Why this belongs in my portfolio

This project connects directly to the skills and practical experience listed in my CV.

## Features

- Task and deadline validation
- Completion and overdue KPIs
- Owner-level workload summary
- Standalone responsive HTML report

## Skills demonstrated

Python, automation, MS Office workflows, HTML reporting

## Run

    python app.py sample_tasks.csv --as-of 2026-08-16 --output operations_report.html
    python test.py

## Project structure

- app.py
- sample_tasks.csv
- test.py

All included sample data is synthetic and safe to publish.
